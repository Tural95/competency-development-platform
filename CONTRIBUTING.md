# Contributing

Thank you for your interest in the project.

The current public repository is primarily a project showcase and documentation space. Constructive contributions are welcome in the following areas:

- accessibility recommendations;
- competency-development methodology;
- responsible AI practices;
- privacy and security guidance;
- documentation improvements;
- ideas for academic and professional use cases.

Before submitting a pull request, please open an issue describing the proposed change. Do not include personal, institutional, confidential, or production data.
